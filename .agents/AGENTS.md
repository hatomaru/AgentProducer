# Workspace Rules

## Agent Tool Calling
エージェントが無限ループに陥り応答を返さなくなる問題（TimeoutやAPIエラー）を防ぐため、以下のルールを遵守してください。

1. **上限回数の明記**: エージェントにツール（検索、実行、その他API呼び出しなど）を持たせる場合、システムプロンプト内で「ツールの呼び出しは最大○回（例: 5回）まで」と明確な制限を設けること。
2. **強制終了の指示**: 特に検索ツール（Web検索など）を使用する際は、過剰なループを避けるため「得られた情報で不十分な場合でも、上限回数に達したらそこまでの情報で必ず回答を生成して終了する」旨を指示に含めること。
